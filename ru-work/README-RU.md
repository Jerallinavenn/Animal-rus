# RU-PATCH v14 — Animal Crossing (USA) GameCube

## Ключевое отличие от v4-v13
Все предыдущие сборки (v4...v13) были сломаны по одной и той же причине:
в них патч текста применялся к ЧИСТОМУ оригиналу, но в чистом оригинале
шрифт НЕ содержит кириллицу — байты карты cyrillic-map указывали на латиницу
с диакритикой, поэтому вместо русского отображалась «белеберда» вида KƉaccÂoe.

v14 собрана принципиально иначе:
1. База — чистый оригинал `Animal Crossing (USA).iso` (27 573 832 байт, GAFE01).
2. Переведённые строки скопированы ПОБайтово из рабочего образа
   `animal-crossing-ru-test-v2/Animal Crossing - RU FONT TEST v2.iso`
   (того самого, который запускался в Dolphin с читаемым русским текстом,
   т.к. ChatGPT дополнительно пропатчила шрифт).
3. Для каждой из 26 строк исходный текст искался сигнатурным поиском по всему
   образу; при нескольких вхождениях выбиралось то, которое ChatGPT реально
   патчила (внутри 4 зон отличий v2 от оригинала). Все 26 записей применены,
   0 ошибок.
4. Хвост файла выровнен до границы 0x800 (27 574 272 байт) — фикс ошибки
   чтения диска в Dolphin.

## Что переводит v14
- Стартовый диалог кота в поезде (message_data id 1124-1126, 1139, 1151):
  «Хм... Эм... Прости... Есть минутка? Поможешь мне?... Как тебя зовут?» и др.
- Варианты ответов в меню (select_data id 3-38): «Да», «Нет», «Привет»,
  «Закончить», «Я переезжаю», «Отстань!», «Ну да!», «Ещё бы!», «Всё верно!» и пр.

## Известные ограничения
- Точное совпадение с v2 по тексту гарантировано побайтовым копированием;
  если в v2 какие-то реплики оставались английскими (id 1151 и хвосты), они
  так и остались английскими — это не регрессия.
- Шрифт: в v14 перенесён ТОЛЬКО текст. Если v2 содержала патченный шрифт в
  зоне 0x15a086d..., а эти байты не относятся к строкам плана — глифы могут
  отличаться. СЛЕДУЮЩИЙ ШАГ: сравнить зоны шрифта отдельно и при необходимости
  перенести их целиком (см. work/v2_regions.json).
