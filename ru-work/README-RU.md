# Animal Crossing (USA) — русский патч v4

Патч RU-PATCH v4 наложен напрямую на `Animal Crossing (USA).iso` (LFS).

## Что сделано в этой версии
- Переведены стартовые диалоги поезда (message_data.bin, id 1124, 1125, 1126, 1139, 1151) — реплики кота/спутника.
- Переведены пункты меню выбора (select_data.bin, id 3, 4, 6, 8, 23–38): «Да», «Нет», «Привет», «Далее» и варианты ответов NPC.
- Все строки упакованы в исходные слоты побайтово точно (длина <= оригинала), без сдвигов данных, размер ISO не изменился.
- Кодировка: кириллица через карту cyrillic-map.json (шрифт-тест v2 от ChatGPT сохранён в animal-crossing-ru-test-v2/).
- Запись select_data id 7 («End») пропущена сознательно: найденное вхождение лежит внутри служебной debug-строки движка (`+---------------End\n`), а не в диалогах.

## Файлы
- `Animal Crossing (USA) [RU-PATCH v4].iso` — патченый образ (готов к запуску в Dolphin).
- `ru-work/records_final.json` — все записи source/russian + абсолютные offset'ы в ISO (база для следующих партий перевода).
- `ru-work/offsets.json`, `ru-work/positions.json` — карта смещений.
- `ru-work/cyrillic-map.json` — кодировка кириллицы.

## Как проверять следующие партии
1. Берём новую пачку строк из message_data/select_data/system_data по offset'ам.
2. Переводим, проверяем длину (русская строка должна быть <= байтовой длины английской после кодирования по карте).
3. Патчим in-place нул-паддингом, пересобираем ISO, SHA-256 сверяем.
