# Animal Crossing RU — статус работ

## Версии образов
- **v4** — первая попытка инлайн-перевода 25 строк (без выравнивания хвоста → ошибка чтения Dolphin).
- **v5** — v4 + выравнивание хвоста до 0x800. Запускался, но текст отображался «коряво» из-за битых токенов переноса (0x7F-последовательности были сдвинуты при кодировании).
- **v6–v9** — эксперименты с базой и картой кодировки. НЕ использовать как основу.
- **v10** — финальная сборка на ЧИСТОМ оригинале `Animal Crossing (USA).iso`:
  * 25 строк переведены побайтово в точные слоты (message_data id 1124,1125,1126,1139,1151 + select_data варианты ответов);
  * **исправлена главная ошибка v5**: все управляющие токены `0x7F XX` (перенос строки, имя игрока, время суток и т.п.) сохранены СТРОГО на своих позициях из оригинала — русские сегменты текста распределены по «карманам» между токенами без их смещения;
  * хвост выровнен до сектора 0x1A4C800 (фикс «Не удалось прочесть диск»);
  * запись select id 7 («End», слот всего 3 байта) пропущена — кириллица физически не влезает, оставлен английский.

## Как работает кодирование
Русские буквы кодируются байтами из `cyrillic-map.json` (поиск ChatGPT/v2): часть букв использует гомоглифы латиницы (А,В,Е,К,М,Н,О,Р,С,Т,Х,а,е,о,р,с,у,х), остальные — редкие ячейки шрифта. Пока НЕ патчен сам шрифт, поэтому «редкие» буквы могут показываться глифами-заменителями. Полный фиксаж требует замены шрифтового RARC-архива — следующий этап.

## Файлы
- `records_v10.json` — все записи с offset'ами и декодированным русским текстом (чертёж для следующих партий).
- `v10_log.json` — журнал сборки.
- `Animal Crossing (USA) [RU-PATCH v10].iso` — образ для теста в Dolphin.
